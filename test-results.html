Requirement: tasks.delete must require user confirmation even when AUTO_CONFIRM_WRITES=true

Security Rationale: Since tasks.delete has risk: 'sensitive', it should ALWAYS require user confirmation regardless of the AUTO_CONFIRM_WRITES setting.

Implementation Location: src/agent/loop.ts:needsUserConfirmation() and src/agent/tools/adapters/tasks.ts:taskDeleteTool

⚠️ Critical Assertion

Even with AUTO_CONFIRM_WRITES=true, the taskDeleteTool must return

  • ok: false
  • error: 'CONFIRMATION_REQUIRED'
